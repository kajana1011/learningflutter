**Repository for learning and practicing Flutter development.** This project contains assignments, examples, and notes to help you grow your Flutter skills — whether you're following a course or learning independently.

## 🚀 What you'll find here

- **Teacher assignments** and guided exercises
- **Self-paced learning materials** and notes
- **Code examples** demonstrating best practices

## ▶️ Getting started

### Requirements
- Flutter SDK (stable)
- Dart SDK (bundled with Flutter)

### Run the app

1. Install dependencies:

```bash
flutter pub get
```

2. Launch on a connected device or emulator:

```bash
flutter run
```

> Tip: Use `flutter doctor` to verify your environment.

## 📁 Project structure

- `lib/` – main Dart source files
- `android/`, `ios/`, `web/`, `macos/`, `windows/`, `linux/` – platform folders
- `test/` – unit and widget tests
